# Agriculture & Crop Production Analysis

## Project Overview

This project analyzes agriculture and crop production data using Microsoft Excel to explore production patterns, crop performance, revenue, costs, profitability, and agricultural factors across different states, seasons, and years.

The project uses data cleaning, PivotTables, PivotCharts, KPI analysis, and interactive dashboards to transform raw agricultural data into meaningful insights.

## Project Objectives

- Analyze crop production across different years and seasons.
- Compare revenue and profitability across crops and states.
- Analyze crop yield and production patterns.
- Explore the impact of soil type and irrigation methods.
- Build interactive dashboards for data exploration and decision-making.

## Dataset

- **Records:** 1,200
